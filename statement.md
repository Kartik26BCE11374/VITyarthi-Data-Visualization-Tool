# Project Statement

## Problem Statement
Students and beginner analysts often need to inspect a dataset and create a suitable visualization without manually deciding which columns are compatible with each chart. The project provides a simple rule-based tool that loads common tabular data formats, profiles the dataset, automatically selects compatible columns, and generates visualizations.

## Scope
The project covers CSV, XLSX, XLS and JSON input, basic dataset profiling, automatic column selection, four chart types, and generation of a text summary and image outputs. It does not attempt to replace advanced BI platforms or perform machine-learning prediction.

## Target Users
- Students learning data visualization and Python.
- Beginners who need quick exploratory charts.
- Instructors evaluating fundamental data-processing and visualization concepts.

## High-Level Features
1. Multi-format dataset loading.
2. Numeric, categorical, date and missing-value profiling.
3. Rule-based chart/column selection.
4. Bar, line, pie and scatter visualizations.
5. Export of chart images and dataset summaries.
6. Validation and automated tests.
